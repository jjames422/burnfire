# Chat Release 2

Release 2 moves the community chat toward a complete alliance communication platform while keeping production changes reviewable through a Vercel preview.

## Included in this preview

- Dependable post-send refresh with clear success and failure feedback.
- Message reactions, replies, editing, author deletion, copying, deep links, unread markers, pins, and private reports.
- Mention discovery and notifications.
- Expanded slash commands: help, action, shrug, guide, bug, roll, poll, spoiler, and clear.
- Browser-native spelling, autocorrection, and capitalization hints.
- A visible account and sign-out control.
- Automated type, migration, and production-build checks on feature branches and pull requests.

## Premium plan (not charging users in this release)

Premium must enhance identity and convenience without selling moderation power or restricting core community safety. Planned offerings include animated profile frames, badges, alliance themes, larger uploads, custom emoji packs, seasonal cosmetics, supporter status, and alliance boosts. Existing entitlement tables remain the authorization boundary. Payments will require a dedicated provider integration, signed webhooks, receipts, refunds, and an administrator ledger before activation.

## Writing assistance plan

Release 2 enables operating-system and browser spelling support. A later preview can add opt-in grammar suggestions through a privacy-reviewed LanguageTool deployment. Private alliance messages must not be sent to a third-party writing service without explicit disclosure and consent.

## Remaining slices

1. Threads, pinned-message browser, search, attachments, and proper report dialog.
2. Direct and group messages, blocking controls, moderator queue, timeouts, and audit interface.
3. Presence preferences, notification controls, polls with structured voting, and custom emoji.
4. Premium storefront, billing integration, cosmetics inventory, gifts, and alliance boosts.
