ドワーフ鉱山は約1週間開催される期間限定イベントです。一見運任せのイベントに見えますし、実際一部は運要素もあります。しかしすべての階層には確定発掘の仕組みが組み込まれており、そのルールを理解すれば必要なつるはしの数を正確に計画できます。最もありがちな失敗は、つるはしを入手した側から使ってしまうことです。

## 仕組み

すべての階層には**12個のタイル**があります。1つには特別報酬が隠されており、残りの11個には通常報酬が入っています。発掘1回につき**ドワーフのつるはし1個**を消費します。通常報酬を発掘するとそのタイルは消えるため、ハズレを引くごとに確率は上がっていきます。特別報酬を見つけると次の階層へ進みます。

手作業で1枚ずつタップしたくない場合は自動発掘機能があり、11月5日のアップデートでさらに高速化されました。

## 全階層に確定発掘が存在

1つの階層をクリアするのに規定回数以上の発掘が必要になることはありません。上限回数は階層の1の位の数字によって決まります：

| 階層の末尾 | 確定発掘回数 |
| --- | --- |
| 1または6 | 6回目 |
| 2または7 | 7回目 |
| 3または8 | 9回目 |
| 4または9 | 6回目 |
| 5または0 | 11回目 |

実際にはこれより早く特別報酬が出ることも多いですが、確定回数があるため最悪のケースを事前に把握できます。末尾が5または0の階層は最も消費が大きい階層です。

## 毎日もらえる無料つるはし

毎日3つのデイリータスクから**計12個の無料つるはし**（各4個）を獲得できます：

- 兵士を280人訓練する。
- ファルコンクエストを1件完了する。
- 同盟技術に6回寄付する。

6日間の開催期間全体で、合計約**72個の無料つるはし**が手に入ります。さらに6個追加で貰えるチャージタスクや、課金によるつるはしパックもあります。

**獲得したつるはしはイベント終了後もバッグに残ります。** 1回の開催ですべて使い切る必要はなく、無課金・微課金プレイヤーにとっては、これこそが最も重要な戦略になります。

## 各階層の到達報酬

発掘で手に入る報酬に加えて、特定の階層に到達すると到達報酬を獲得できます：

| 階層 | 報酬 |
| --- | --- |
| 5 | ビトリウム ×2,000 |
| 10 | ビトリウム ×4,000 |
| 20 | ランダムビトリウム補給箱 ×8（1個あたり1,000～10,000ビトリウム） |
| 30 | 装備選択サプライ ×5 |
| 40 | 装備選択サプライ ×5 |
| 60 | 装備選択サプライ ×10 |
| 80 | 装備選択サプライ ×10 |
| 100 | **MR装備設計図 ×10** |

装備選択サプライでは、UR装備設計図1枚、強化鋼材 ×100、ビトリウム ×3,000のいずれか1つを選択できます。

最も重要なのは100層です。MR装備設計図はUR 4★装備をMR 5★に昇格させるために不可欠な素材であり、他の入手手段は限られています。10枚入手できれば、エンドゲーム装備の作成へ大きく前進します。

## 毎階層で賞品を選択

発掘を始める前に、星付きタイルをタップしてその階層で獲得する特別賞品を選択できます。選択肢は階層ごとに異なり、「デフォルトに設定」にチェックを入れることで毎回選ぶ手間を省けます。

選択肢の1つに**ハーブレベルサプライ（SSR）**があり、その獲得量は聖域レベルに応じてスケールします。高レベルのアカウントでは、1つのサプライで数十万のハーブに相当します。ゲーム終盤のアカウントでは装備の石が余りがちになる一方で、研究用のハーブは常に不足するため、多くの熟練プレイヤーはハーブをデフォルトに設定しています。まだ装備を強化中の段階であれば、装備の石を選択する方が役立つ場合もあります。

## 実際に必要なつるはしの数

1層から99層までの全階層で確定回数までかかった場合、100層に到達するには**769個のつるはし**が必要になり、100層自体をクリアするには**780個**が必要です。これが理論上の最悪のケースです。

実際にはほとんどの場合、確定前に特別報酬を見つけられるため、より少ない数で済みます。運次第ですが、実際には約**440～670個のつるはし**で到達できると見積もられています。途中でつるはしが切れて92層などで立ち往生しないよう、ほとんどのガイド制作者は100層狙いの周回を始める前に**少なくとも750個**貯めることを推奨しています。

1回の開催あたり72個の無料つるはしが得られるため、無課金プレイヤーが750個貯めるには約10回のイベント開催を経る必要があります。長く感じるかもしれませんが、少量のビトリウムで終わるか、10枚のMR装備設計図を手に入れるかの決定的な差となります。

## BF2の推奨立ち回り

イベント開催中は毎日3つのデイリータスクをこなしましょう。これらは日常的に行う日課が中心であり、ここから12個の無料つるはしを獲得できます。そして**発掘はしないでください**。750個以上貯まるまでイベントを跨いでつるはしを蓄積し、準備ができたら一気に100層まで登り切りましょう。

まだ750個に遠く及ばず、当分届きそうにない場合は、序盤の到達報酬（ビトリウムが手に入る5層、10層、20層は少ない消費で到達できます）を狙って掘るのも問題ありません。ただし、序盤で使ったつるはしは、後でMR設計図を狙う際、再び集め直す必要があることを覚えておいてください。

<Callout variant="tip" title="要約">毎日無料つるはし12個、1回のイベントで約72個。750個貯まるまでイベントを跨いで温存し、一気使いで100層を完走してMR装備設計図10枚を獲得しよう。</Callout>
