矮人矿山是持续约一周的限时活动。它看起来像个凭运气的游戏，某种程度上也确实如此。但每一层都有内置的保底机制，一旦了解其运作方式，你就可以精确规划所需的镐子数量。玩家犯的最大错误就是一拿到镐子就立刻用掉。

## 运作机制

每一层有**12个方格**。其中一个隐藏着特殊奖励，其余11个则是普通奖励。每次挖掘消耗**一把矮人镐子**。当挖出普通奖励时，该方格就会消失，因此每次未中都会提高下一次的概率。找到特殊奖励后，你就会进入下一层。

自动挖掘功能可以在不想手动点击每个方格时使用，11月5日的补丁使其速度更快。

## 每一层都有保底挖掘

你绝不需要超过固定次数的挖掘就能清完一层。该上限取决于楼层数的最后一位数字：

| 楼层尾数为 | 保底挖掘次数 |
| --- | --- |
| 1 或 6 | 第6次 |
| 2 或 7 | 第7次 |
| 3 或 8 | 第9次 |
| 4 或 9 | 第6次 |
| 5 或 0 | 第11次 |

你通常会在此之前就拿到特殊奖励，但保底机制意味着最坏情况可以提前预知。尾数是5或0的楼层属于消耗较大的楼层。

## 每天免费镐子

你可以通过三个每日任务每天获得**12把免费镐子**，每个任务4把：

- 训练280名士兵。
- 完成1次猎鹰任务。
- 捐赠联盟科技6次。

在为期六天的活动期内，这大约是**72把免费镐子**。此外还有一个充值任务可额外提供6把，如果氪金还可以购买镐子礼包。

**活动结束后，你的镐子会保留在背包中。**你不需要在单期活动中全部用完，对零氪玩家来说，这就是整个策略的核心。

## 各楼层奖励

除了挖出的奖励外，达到特定楼层还能获得里程碑奖励：

| 楼层 | 奖励 |
| --- | --- |
| 5 | Vitrium ×2,000 |
| 10 | Vitrium ×4,000 |
| 20 | 随机Vitrium补给箱 ×8（每个1,000–10,000 Vitrium） |
| 30 | 自选装备补给 ×5 |
| 40 | 自选装备补给 ×5 |
| 60 | 自选装备补给 ×10 |
| 80 | 自选装备补给 ×10 |
| 100 | **MR装备图纸 ×10** |

每个自选装备补给箱可让你从以下奖励中任选一种：UR装备图纸、淬火钢 ×100，或 Vitrium ×3,000。

第100层才是关键所在。MR装备图纸是将UR 4★装备升阶至MR 5★所需的材料，而且几乎没有其他获取途径。10张图纸是迈向终局装备的大步跨越。

## 挑选每一层的奖励

在开挖之前，轻触带星号的方格选择该层发放的特殊大奖。选项随楼层变化，你可以勾选“设为默认”，这样就不用每次都重新选择。

选项之一是**草药等级补给（SSR）**，其价值会随避难所等级而提升。在高级账号上，单份补给就价值数十万草药。后期账号往往拥有多到用不完的装备石，而草药在科技研究中总是短缺，因此大多数经验丰富的玩家都会将草药设为默认选择。如果你仍在打造装备，装备石选项可能更适合你。

## 实际上需要多少把镐子

如果从第1层到第99层的每一层都触及保底，达到第100层需要**769把镐子**，而清空第100层本身需要**780把**。这是真正意义上的最坏情况。

你几乎总会在保底前找到特殊奖励，所以大多数通关所需的镐子更少。根据运气的不同，预估消耗大约在**440至670把镐子**之间。大多数创作者建议在开始完整通关前**至少积攒750把**，以免卡在第92层却没有镐子可挖。

按照每期72把免费镐子计算，零氪玩家需要大约积攒十期活动才能存够750把。这听起来很多，但这就是只能拿到少量Vitrium与直接拿到10张MR装备图纸之间的差距。

## BF2的操作建议

活动开放的每天都完成三个每日任务。这些任务大多是你平时就会做的操作，也是12把免费镐子的来源。然后**切勿挖掘**。让镐子跨期不断积攒，直到拥有750把或更多时，再一鼓作气直接通关全部100层。

如果你距离750把还很远且相当长时间内无法达到，也可以去挖早期里程碑（第5、10和20层成本低且奖励Vitrium）。只要明白早期消耗的每一把镐子，以后为了MR图纸都必须重新补回来。
