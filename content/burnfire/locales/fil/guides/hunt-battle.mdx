Ang Hunt Battle ay event ng alliance kung saan umaatake sa teritoryo natin ang mga wave ng Blights at sama-samang lumalaban ang buong alliance. Isang attempt lang ito bawat event at hindi na mababago ang difficulty kapag napili na, kaya kailangang planuhin bago magpadala ng march. Basahin ito bago magsimula para alam ng lahat ang gagawin.

## 1. Paano gumagana ang Hunt Battle

- **Event para sa buong alliance, hindi laban ng dalawang alliance.** Walang kalabang alliance; lahat ay nakikipaglaban sa Blights.
- **Kailangan ng 20 o higit pang aktibong miyembro.** Mahalaga ang pagiging aktibo: hindi nakatutulong ang mga hindi sasali sa pag-clear ng wave.
- **R4 o R5 lang ang maaaring magsimula.** Pamunuan ang pipili ng oras at difficulty.
- **Lumilitaw sa mga wave ang Blights sa ating teritoryo.**

## 2. Ang mga wave

| Yugto | Mangyayari |
| --- | --- |
| Panahon ng paghahanda (5 minuto) | Wala pang labanan. Mag-online, ihanda ang squad, at pumuwesto. |
| Waves 1–15 | Darating ang 15 wave, **bawat isa ay mas mahirap kaysa nauna**. |

**Nakatakda sa 15 segundo ang travel time ng bawat march para sa lahat.** Walang epekto ang layo: kasindali makarating ng miyembrong malayo sa labanan gaya ng katabi nito. Makakatulong ang lahat sa bawat wave; walang “sobrang layo.”

## 3. Pagpili ng difficulty

- **Naka-lock ang difficulty kapag napili na.**
- **Isang attempt bawat event.**
- **Mas mabuti ang kumpletong clear kaysa bahagyang clear sa mas mataas na difficulty.**

Nakakatukso ang mas mahirap na difficulty, pero kung ma-stuck ang alliance sa wave 11, doon matatapos ang run. Buong reward ang makukuha sa mas madaling difficulty na kayang tapusin. Piliin ng leadership ang antas batay sa mga aktuwal na makakapag-online at lalaban, hindi sa kayang i-solo ng pinakamalalakas na account.

<Callout variant="tip" title="Mas mahalaga ang clear kaysa ambisyon">Piliin ang difficulty na talagang kayang tapusin ng alliance. Isang attempt lang ang mayroon kayo.</Callout>

## 4. Mga utos ayon sa wave

Lalong humihirap ang wave kaya nagbabago ang plano sa tatlong yugto:

- **Waves 1–5: tuloy-tuloy na mag-deploy.** Pinakamadali ang mga unang wave. Panatilihing umaandar ang march para mabilis malinis at hindi dumami ang kalaban.
- **Waves 6–10: tutukan ang mga target na tinawag sa chat.** Huwag magkalat; sundan ang target. Mas mabilis mapapatumba ng pinagsamang damage bago ito makalamang.
- **Waves 11–15: i-activate ang buff bago ang wave 11.** Pinakamahirap ang huling wave. Dapat aktibo na ang buff **bago** magsimula ang wave 11, hindi kapag umaatake na ito.

## 5. Command checklist ng BF

Isang trabaho ang hawak ng bawat role:

| Role | Responsibilidad |
| --- | --- |
| **God of War** | Namamahala sa event. |
| **Recruiter** | Nagbibilang ng aktibong miyembro — tiyaking 20+ bago magsimula. |
| **Goddess** | Sinusuri ang paghahanda bago ang labanan. |

## Bago magsimula: checklist ng miyembro

- Mag-online sa oras ng event — kailangan ng 20+ aktibong miyembro.
- Gamitin ang 5 minutong paghahanda para ihanda ang mga squad.
- Ihanda ang mga buff para i-activate bago ang wave 11.
- Bantayan ang chat para sa tinawag na target simula wave 6.
