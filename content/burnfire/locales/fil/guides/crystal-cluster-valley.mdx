## Mga gantimpala ng event

Pinagsasama ng Crystal Cluster Valley ang mga kaalyado at kalaban sa iisang event map, pero personal ang ranking. Hindi naaapektuhan ang hukbo sa tahanan ng mga troop loss na para lamang sa event, kaya mag-deploy nang agresibo hanggang sa barracks limit.

## Inirerekomendang timeline

- **0–2 minuto:** lumapag at gamitin ang libreng teleport kung hindi maganda ang puwesto.
- **2–10 minuto:** talunin ang Plague Rats para sa skill progress at mangalap lamang sa Level 3 nodes.
- **10–12 at 20–22 minuto:** unahin ang Instant Crystal Waves.
- **23–30 minuto:** labanan ang Sacred Cave; ang huling pitong minuto ang magtatakda ng mahalagang ranking.

Gumamit ng maraming march, magdala ng Stamina Diamonds, at ihanda ang teleport item. Nagre-refresh kada anim na minuto ang isang libreng balik; mas mahal ang mga susunod na paglipat.
